# n8n-automation-workflows-aiAgents

A collection of n8n workflows built around AI Agents — from single-agent
automations to multi-agent orchestration setups. Each folder contains a
self-contained workflow (exportable `.json`) along with its own
documentation covering the agent's purpose, tools, and setup steps.

More agent-based workflows will be added over time — single-purpose
agents, RAG-based assistants, and other automation experiments.

**Requirements (general):** an n8n instance, LLM provider credentials
(e.g. OpenRouter/OpenAI), and whatever app-specific credentials a given
workflow's tools require (see each workflow's own README).
